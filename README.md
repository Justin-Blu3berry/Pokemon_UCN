## Project Overview
This is the indie game I'm working on in my spare time (the title is likely to change before I get a release build ready). 

This repository contains all of the project files that aren't visual or auditory assets (it would be unreasonable to store such large files on GitHub), including scripts, input mapping, and the JSON objects that represent the menus and scenes that my game uses. 

This project took a lot of inspiration from Scott Cawthon's *Ultimate Custom Night*, Emil Macko's *Five Nights at Candy's*, and the mod *Five Nights at Candy's But Better* by Evil Wacko, Mr. Manatee, Nephryte. Originally, this started with me revisiting the version I had made on Scratch when I was 15 and deciding that I could do a lot better with the characters' mechanics, the gameplay loop, the visuals, and... pretty much everything. I started this project on Scratch because I didn't know any other game engines and found that after years of programming in Python, block-based programming was no longer for me. This led me to researching different languages and game engines, ultimately settling on Lua for the comfort of it feeling very similar to Python and Defold thanks to it being open-source engine with easy-to-find documentation. Learning the quirks of this language and this engine has been so much fun that the very act of sitting down to work on the game is enjoyable in its own right.
